So when I was thinking what should I discuss about, obviously there is a pending quantum post, which I will continue. But for this post I wanted to cover something which is related to the computer science world and in general our world as well.

So in this post I will be discussing the concept of P vs NP, which is a very interesting topic in computer science and mathematics. I mean why wouldn't it be? It's one of the seven Millennium Prize Problems which is a set of problems in mathematics that were stated by the Clay Mathematics Institute in 2000, and if you solve any of them you get a prize of $1 million.

And till date only one of those seven problems has been solved, which is the Poincaré Conjecture (which again I will be covering in another blog). So the P vs NP problem is still unsolved.

So I will be trying to cover the background of the P vs NP problem and trying to explain it in the best way possible for me. So now what's this P vs NP? Basically it asks whether every problem whose solution can be verified quickly can also be solved quickly.

Now "quickly" here means that it can be computed in polynomial time (O(n), O(n log n), etc.), so the class of questions which can be solved in this bounded time are known as class "P" problems. But some problems cannot be solved in polynomial time, but if given an answer, can be verified in polynomial time. We will use some examples to understand this problem to get more clarity.
