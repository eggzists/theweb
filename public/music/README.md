Put audio files for posts here (mp3, m4a, ogg or wav), e.g. `public/music/my-song.mp3`,
then reference them in `src/content/posts.ts` as `music: { title, artist, src: "/music/my-song.mp3" }`.

Only use audio you have the rights to share. For other songs, use a YouTube (full song) or Spotify link instead:
`music: { title, artist, youtube: "https://www.youtube.com/watch?v=..." }`.
